Problem 1: Multi-Year Investment Strategy¶

A hedge fund has \$150,000 to invest over a four-year horizon. There are four investment options available:

  • Annuity: The fund can invest the same amount at the beginning of years 1, 2, 3, and 4, and receive 140\% return on the total capital at the end of year 4. This option has restriction, if you invest any amount in year 1, you must invest the same amount in every year after that!

  • Savings Account: The fund can invest any amount at the beginning of each year to receive the capital plus 5\% return at the end of each year. They can also borrow up to \$25,000 at the beginning of each year, to be repaid with 5\% interest at the end of the year.

  • Tech Startup Investment: At the start of the year 2, an opportunity to invest in a promising tech startup becomes available. The fund can invest up to \$75,000 in this option. If they choose to invest, they will receive the invested capital plus 150\% return at the end of the fourth year. (Notice, here you get not 150\% in total but invested capital PLUS 150\% return).

  • Real Estate Fund: This option becomes available from year 3. The fund can invest any amount at the start of 3rd or 4th year, and they will receive 110\% of the invested capital at the end of year 4.

The hedge fund aims to maximize its total payout at the end of the four-year period.

Question 1.1: Formulate this as a linear programming problem mathematically (write objective function and constraints in the next cell (below) which is in a markdown mode).¶

The objective functions:

  1. Fund invests $4x_1$ in annuity to get $1.40\cdot 4x_1$
  2. At the begining of year 4 fund has $x_5$ on the bank account and will get 5\% return on it, $1.05x_5$
  3. Fund can invest $x_6$ in the startup at the start of year 2 to get $(1+1.50)x_6$ at the end of year 4.
  4. Invest $x_7$ in year 3 and $x_8$ in year 4 and get $1.1\cdot x_7+1.1\cdot x_8$

So in total, fund will have: $$1.40\cdot 4x_1 + 1.05x_5 + 2.50x_6 + 1.1x_7 + 1.1x_8$$

Constraints:

  1. At the begining of the first year fund can split 150 000 between annuity and bank: $x_1+x_2=150 000$
  2. At the begining of the second year, fund gets $1.06x_2$ from investing $x_2$ in the first year: $x_1+x_3+x_6=1.05x_2$
  3. At the begining of the third year, fund has bank balance $1.05x_3$ (either positive or negative amount). In year 3 $x_1$ goes to annuity and $x_4$ (positive or negative amount) to bank and $x_7$ to real estate: $x_1+x_4+x_7=1.05x_3$
  4. At the begining of year 4, again annuity $x_1$, bank $x_5$ and real estate $x_8$, while fund has $1.05x_4$. So, $x_1 + x_5 + x_8 = 1.05 x_4$

We can rewrite all of this in linear programming framework:

\begin{split} \begin{aligned} \max_{x} \ & 1.40\cdot 4x_1 + 1.05x_5 + 2.50x_6 + 1.1x_7 + 1.1x_8 \\ \mbox{subject to } \ & x_1 + x_2 = 150,000\\ & x_1 - 1.05 x_2 + x_3 + x_6 = 0\\ & x_1 - 1.05 x_3 + x_4 + x_7 = 0\\ & x_1 - 1.05 x_4 + x_5 + x_8 = 0\\ & x_2 \ge -25,000\\ & x_3 \ge -25,000\\ & x_4 \ge -25,000\\ & x_5 \ge -25,000\\ & x_6 \le 75,000\\ & x_j \ge 0, \quad j = 1,6,7,8\\ & x_j \ \text{unrestricted from above}, \quad j = 1,2,3,4,5,7,8\\ \end{aligned} \end{split}

Problem 2: Modified Schelling's Segregation Model¶

Set up:

  • We have two types of agents: 300 orange agents, 200 green agents and 500 blue agents
  • They all live on a single unit square
  • Each agent has a location (x, y), where $x\in(0, 1)$ and $y\in(0, 1)$

Preferences:

Preferences depend on 10 nearest neighbors (in term of euclidian distance). An agent is happy if at least 4 of the 10 nearest neighbors are the same type and unhappy otherwise.

Actions:

Agent can move or stay based on happiness.

Timeline:

  1. Agents are randomly allocated in a unit squre, in other words, their location is randomly drawn from bivariate uniform distribution from (0, 1).

  2. In every period, each agent simultaniously decided to move or stay:

    • Stay if happy
    • Move if unhappy and draw new location from bivariate uniform distribution from (0, 1)

Game continues until eveyrone is happy!

# Write a function which takes, locations, number of neighbours that need to be considerd and happyness condition
# as an argument, prints at each iteration number of agents who moved and outputs updated data where everyone is 
# happy

def scheling(data_agents, neigbours, happy_condition):
    
    # first we need to make a copy of the original data here in order to keep the original and reuse it below in 
    # question 2.4
    
    data = data_agents.copy()

    
    # Let's assign initial value to unhappy = 1 
    unhappy = 1
    

    # In order to count how many iterations it takes to converge (nobody to be willing to move) we also define iteration 
    # as zero and increae this nunmber by one each time while loop happens
    iteration = 0

    # as we said, in order to get the while loop started, the initial condition should be true. By initial assignment
    # unhappy=1 so  it is > 0:

    while unhappy>0:
        # create a placeholder where we store all the agents that moved.
        moved=[]

        # to keep the original data unafected until all the agents decide to move or not in each iteration
        # we make a copy of it
        data_temp=data.copy()

        # now we loop over each agent to see if they want to move or not
        for agent in data.index.tolist():

            # their moving decision depends on number of similar types aroud the agent. We calculate distance manually
            # one step at a time, but you can put all in one line

            # first calculate elementwise difference between the given agents lication and everyone esle
            diff = data_temp[['x', 'y']]-data_temp.loc[agent, ['x', 'y']]

            # square each coordinate difference
            sq_diff = diff**2

            # sum squares of differences
            sum_sq_diff = sq_diff.sum(axis=1)

            # take  a square toot from the sum
            sqrt_sum_sq_diff = sum_sq_diff**0.5

            # in the temporary dataframe add a column which containes distance between a given agent and everyone else
            # includine the agent hersels (the distance between agent and herself should be zero)
            data_temp['sqrt_sum_sq_diff'] = sqrt_sum_sq_diff

            
            # The agent will be unhappy if less then 4 are the same type, so the agent is unhappy if the number is < happy_condition.

            if sum(data_temp.sort_values(by='sqrt_sum_sq_diff')['type'][1:neigbours+1]==data_temp.loc[agent, 'type'])<happy_condition:
                # if the condition is met, the agent is unhappy and moves. 
                # We will append list "moved" where we store all the agents who moved in a given iteration
                moved.append(agent)

                # Since the agent moves we will update her location in the original(!!!) data not in the copied version! 
                data.loc[agent, ['x', 'y']]=np.random.uniform(0, 1, size = (1, 2))[0]

        # After we check every agent, we find how many people where unhappy and if number is more than 0 while loop continues
        unhappy=len(moved)

        # At this point the iteration is done and we increase it by one to keep the record of how many iterations we are doing
        iteration += 1

        # to keep infromation coming at every iteration we print out what is happening in our code
        print('On iteration: '+str(iteration)+': '+str(len(moved))+' agets moved')
        
    return data
